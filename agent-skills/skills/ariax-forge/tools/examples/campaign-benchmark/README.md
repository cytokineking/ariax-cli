# Saved campaign benchmark example

Discover this directory through ariax skills forge --json and read the
campaign-benchmark and campaign-benchmark-methods references through either
platform alias. Follow the primary guide's actual Forge commands.

| File | Purpose |
| --- | --- |
| plan.json | Three exact public candidates and finite cutoffs; accepted recipe heads must be populated from coordinator acceptance before execution. |
| benchmark.py | prepare verifies raw B70 inputs/results and stages four chain queries; report regenerates all 24 JSON/TSV/Markdown report files. Python stdlib only. |
| qc.py | Exact native chain sequence and finite complete N/CA/C/O check. Run in the selected design-qc image with gemmi 0.7.3. |
| search.py | One explicit complete-database CUDA easy-search; saves native log, resources, full-call elapsed time and command ID. |
| results.py | Joins actual saved QC/search calls and optional sanitized cost/interval records. |
| report-files.json | All 24 expected report paths for complete installed-consumer comparison. |

All molecular outputs stay in the restored campaign checkpoint. Under
/workspace/benchmark, preserve b70/campaign-delivery/campaign.json and every
original referenced file, plus b70/campaign-shortlists/shortlists.json. The root
also contains prepared/, new/qc/, new/search/, results.json and report/.
Register all five source inputs under /inputs/campaign-benchmark and observe
their import IDs until ready. Keep installed paths distinct from these container
paths. Source, image, asset and compute preparation follow the live catalog.

Every recovered table comes from the saved selection, results and original native
files. Choose a fresh report output directory and compare each generated path and
byte. report.json lists the complete native input closure by relative path and size,
including prepared chain queries and saved call records. Failed original candidates remain in the report. New generation, prediction
and search calls are absent from report recovery. No scientific outputs or
experimental observations are bundled with this source example.
