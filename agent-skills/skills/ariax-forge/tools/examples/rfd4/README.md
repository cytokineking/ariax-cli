# RFd4 example inputs

`data.examples.rfd4` from `ariax skills forge --json` locates this directory
in an installed CLI. The [baseline](baseline/README.md) contains a monomer
specification and its annotated CIF, plus a PD-L1 binder specification and its
cropped target CIF. Retain each pair's relative layout when staging. See the
[RFd4 guide](../../rfd4.md) for complete upload and generation commands.

These upstream-derived inputs have bounded native checks. Consult the live
catalog for the current supported scope and resources. They are not evidence of
binding or biological activity. Source attribution
and the applicable notice are retained with the [baseline files](baseline/README.md).
The binder specification adapts upstream documentation, whose text declares
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); see the attribution in
the [RFd4 guide](../../rfd4.md).
