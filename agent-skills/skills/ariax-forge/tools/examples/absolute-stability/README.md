  imposing a predicted score threshold or claiming new experimental evidence.

The adapter normalizes only selected protein chains to a scratch CIF, in
requested order, as native A/B with sequential residue indices. Saved results
map every position back to author chain, number and insertion code. Input
coordinates are retained through CIF; upstream SaProt separately isolated
chains use its temporary PDB preparation. Resolve alternate conformations,
noncanonical protein residues and multiple structural models explicitly first.

The October 9 L40 completion also generated 128/512-residue resource fixtures
remotely from this domain, with translated coordinates and explicit AA/BB author
maps. These artificial inputs and their complete outputs are retained privately
with runtime evidence, rather than shipped as biological examples. See
qualification for measured cases,
resource recommendations and the distinction between execution and calibration.
