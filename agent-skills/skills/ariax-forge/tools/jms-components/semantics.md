# JMS definitions and compatibility limits

Reference: [Joint_Model_Stability commit 954f0a14d9dd77daa54c41023befbc245e279b4d](https://github.com/yehlincho/Joint_Model_Stability/tree/954f0a14d9dd77daa54c41023befbc245e279b4d). The adapters use the score definitions below and the loader choices described here. The demonstrated input is 1CRN chain A residues 1–46. Experimental stability accuracy and larger-input capacity remain unestablished.

| Quantity | Exact meaning | Interpretation limit |
| --- | --- | --- |
| `esm_pp` | `exp(mean_i[-log p(s_i | sequence with i masked)])` for ESM2-650M | Pseudo-perplexity; lower is higher model support for the sequence. |
| `log_esm_score` | `-log(esm_pp)` | Mean log pseudo-likelihood, in nats per residue. |
| `conditional_CE` | Native-residue mean NLL from ColabDesign `get_logits()` | Autoregressive prior-residue conditioning under one recorded seed, not upstream all-other-residue conditional probabilities. |
| `unconditional_CE` | Mean NLL from ColabDesign `get_unconditional_logits()` | Structure-conditioned sequence score with zero autoregressive mask. |
| Legacy `log_CE` | Mean `-log(p_reference_distance_bin + 1e-8)` over all L² pairs | Reference virtual Cβ, including glycine; diagonal and ordered pairs retained. |
| Legacy `CE` | Mean reference-distance-bin probability over all L² pairs | The notebook calls this CE, but it is a probability average, not cross-entropy. |
| Legacy `PLDDT` | Mean atom-index-1 pLDDT from full-sequence inference | 0–100; zero-recycle fixture differs from half-mask two-recycle input. |
| `avg_mask_esmfold_plddt_recyc2` | Mean of eight reference half-mask pLDDT samples at seeds 0–7 | Historical beta inference draws a new Bernoulli mask before each folding pass; preserve all two-recycle settings. |

ProteinMPNN preserves the 21-class softmax denominator in AF order `ARNDCQEGHILKMFPSTWYVX`. The script default checkpoint is `v_48_010`; its helper default is `v_48_020`. Both are exposed explicitly, while hybrid 1 requires the script default. The shared `proteinmpnn` model's JMS directory is `/models/proteinmpnn/colabdesign/v1.1.0`, containing official `v_48_010.pkl` and `v_48_020.pkl` from ColabDesign `e7c38e5e70cac56f20f99efbf9d98707c1383ff1`. The native PyTorch checkpoints have separate `vanilla/` and `ca/` paths and are not replacements for this JAX interface.

ColabDesign v1.1.0 contains an older [Beer-Ware Revision 42 notice](https://github.com/sokrypton/ColabDesign/blob/e7c38e5e70cac56f20f99efbf9d98707c1383ff1/af/LICENSE.txt) at `af/LICENSE.txt`. The maintainer's [repository-wide licensing statement](https://github.com/sokrypton/ColabDesign/issues/180#issuecomment-2393957169) accompanies the [later root Beer-Ware notice](https://github.com/sokrypton/ColabDesign/blob/d193e44f77a8f382cdd8fdb49c565c17e61fa13a/LICENSE.txt). The JAX010/JAX020 parameters also appear in the later licensed tree. Retain both notices; the selected older executable source's licensing scope remains unresolved. Native ProteinMPNN retains its separate MIT notice.

The old [Transformers fork pinned by JMS](https://github.com/liujas000/transformers/blob/6b4b7687810eafb083a5216feefca86c376ab228/src/transformers/models/esm/modeling_esm.py) predates ESM2 rotary encoding. The ESM2 adapter uses official Transformers 4.30.2 and the named [650M checkpoint config](https://huggingface.co/facebook/esm2_t33_650M_UR50D/blob/main/config.json) with the original score equation. The reference batches all L masked rows in one forward; the adapter defaults to mask batch 8 and preserves every residue.

Legacy ESMFold uses the `esmfold.model` URL from [JMS setup](https://github.com/yehlincho/Joint_Model_Stability/blob/954f0a14d9dd77daa54c41023befbc245e279b4d/setup.sh). JMS's historical masked notebook installs `sokrypton/esm@beta`. The tool uses [f3a279871f9bf67c13beb7f3bdbf907e0f3306b1](https://github.com/sokrypton/esm/tree/f3a279871f9bf67c13beb7f3bdbf907e0f3306b1), whose `mask_rate` and `return_contacts` interface matches the reference. It applies `torch.rand(aa.shape, device=aa.device) < 0.5` to LM residue tokens before BOS/EOS, retains original folding tokens, and refreshes the mask/LM features for each recycle. Two recycles mean three folding passes per seed. Eight seeds 0–7 run in eval mode, with contacts true, linker `XX`, index offset 512 and chunk size 128. Final atom-index-1 pLDDT is averaged over residues and seeds.

The beta code and official ESMFold model card state MIT; retain the applicable upstream notices. Missing inputs produce unavailable hybrids.

The [aggregation notebook](https://github.com/yehlincho/Joint_Model_Stability/blob/954f0a14d9dd77daa54c41023befbc245e279b4d/Stability_Prediction.ipynb) defines consistent hybrid 1/3 formulas and records fitted ratios 0.9 and 0.85625. The [published paper](https://www.nature.com/articles/s41467-025-66526-w) rounds hybrid 3 to 0.86 and publishes supplementary data containing the exact recycle-two pLDDT and ESM score columns. The unit check covered a 77-row sample: raw 0–100 pLDDT and negative log pseudo-perplexity. The older `Half Masked ESMFold Average Plddt` column differs from `avg_mask_esmfold_plddt_recyc2` and must not replace it. The aggregate records explicit units and user-supplied ratios; full-dataset refitting remains unrun. Hybrid 5 changes its constituent between training and test and is not implemented. Hybrids 2/6 require AF2, and hybrid 4 requires ESM-IF.

Keep model names, structure identity, seeds and conditions with comparisons. These quantities assess model support/confidence for a chosen input. They do not establish binding, expression, specificity or experimental ΔG. ESMC, ESMFold2 and the separate legacy predictors have different scientific definitions and support limits.
